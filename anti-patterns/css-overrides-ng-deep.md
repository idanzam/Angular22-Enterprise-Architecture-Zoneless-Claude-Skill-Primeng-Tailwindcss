# ⛔ Anti-Pattern: Custom CSS & `::ng-deep`

## The crime

Component `.css` files with rules in them — above all, the `::ng-deep`
PrimeNG override:

```css
/* ❌ the classic graveyard */
:host ::ng-deep .p-datatable .p-datatable-thead > tr > th {
  background: #1e293b !important;
  padding: 6px 10px !important;
}
:host ::ng-deep .p-dialog .p-dialog-header { border-bottom: 1px solid #333; }
.my-card { margin-top: 16px; box-shadow: 0 2px 8px rgba(0,0,0,.15); }
```

## Why it's fatal

- `::ng-deep` is deprecated, pierces encapsulation globally (it leaks beyond
  the component), and couples you to **PrimeNG's private DOM** — any minor
  release may rename `.p-datatable-thead` and your override dies silently.
- `!important` wars escalate: the next dev needs `!important` + higher
  specificity, and the cascade becomes archaeology.
- Hardcoded colors/paddings bypass the design-token system — dark mode and
  theme switching break for exactly those elements.
- Every rule in a `.css` file is a rule Tailwind's compiler can't see, dead
  code detection can't reach, and the layer contract can't order.

## The fix — climb the ladder, stop at the first rung

```html
<!-- 1. Tailwind utility on your own markup -->
<span class="mt-4 shadow-lg/25">…</span>

<!-- 2. class on the PrimeNG host -->
<p-card class="mt-4 shadow-lg">…</p-card>
```

```typescript
// 3. global look → preset tokens
const MyPreset = definePreset(Aura, {
  components: { datatable: { headerCell: { background: '{surface.800}', padding: '0.375rem 0.625rem' } } },
});
```

```html
<!-- 4. one instance → [dt] scoped tokens (THE ::ng-deep replacement) -->
<p-datatable [dt]="denseTable" … />

<!-- 5. structural → [pt] pass-through with Tailwind classes -->
<p-table [pt]="{ headerCell: 'bg-surface-800 text-surface-0 py-1.5 px-2.5' }" />
```

There is no rung 6. If none of 1–5 fits, the missing token exists and you
haven't found it — query the `primeng` MCP (`get_component` lists every
component's tokens) or check the component doc's Theming section.

## The residue rule

`styles.css` is the only stylesheet (Tailwind config + `@theme` tokens).
Component `.css` files generated by the CLI stay **empty** — an empty file is
a green flag in review; a non-empty one is a finding.

## Detection

```bash
grep -rn "ng-deep\|!important" src/app --include='*.css' --include='*.scss'
find src/app -name '*.css' -size +0c          # any non-empty component stylesheet
grep -rnE "styles:\s*\[" src/app --include='*.ts'   # inline styles arrays
```
